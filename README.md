# corex-survival

> Survival stats (hunger/thirst/stamina) for COREX Framework

Part of the [COREX Framework](https://github.com/ABUGIZA/COREX-Framework).

## Install

Drop the `corex-survival` folder into:
```
server-file/resources/[corex]/corex-survival/
```

Make sure it loads after `corex-core`:
```cfg
ensure corex-core
ensure corex-survival
```

## Update

Download the latest release ZIP from the **Releases** tab and replace the folder.
